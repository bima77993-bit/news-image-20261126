# Thursday 26 November 2026 — The World in One Day

One 1024×1024 image summing up 26 November 2026's world news: 40 verified stories in three heroes (Houthis claim a Ras Tanura refinery strike as Brent jumps to ~$94.80, Trump proposes tariffs on 14 partners as markets slide, Kim Jong Un orders wider tactical nuclear deployment), twelve more top stories, sixteen briefs, nine micros, plus a world map, a UTC timeline, a date check, and a CLAIMED vs CONFIRMED honesty box so claims are never shown as facts.

`main.ts` (Node 22, stdlib only) validates the PNG — signature, full CRC-32 chunk walk, 1024×1024 dimensions, 1 MiB limit — and copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`.
